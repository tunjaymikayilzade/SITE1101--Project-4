# Tunjay Mikayilzade — Personal Portfolio

A responsive personal portfolio for the SITE 1101 Project 4 assignment.

## View locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript
and does not require a build step.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select the `main` branch and the
root folder as the publishing source, then save. The site will be available at:

`https://tunjaymikayilzade.github.io/SITE1101--Project-4/`

The portfolio includes a home introduction, an interactive platform game that
reveals personal details, and a Projects section with a playable OR gate and
the Group 18 Project 1 contribution table. The platform game is controlled with
the A, D, and Space keys.

The Project 1 team photo is stored locally as `project-1-team.png`.
