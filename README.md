# Tunjay Mikayilzade — Personal Portfolio

A personal portfolio website made for the SITE 1101 (Principles of Information Systems) Project 4 assignment at ADA University.

**Live website:** https://tunjaymikayilzade.github.io/SITE1101--Project-4/

## About the project

The website introduces me, my background, my skills and my projects. It is built with plain HTML, CSS and JavaScript, so it needs no build step, and it is hosted on GitHub Pages.

## Sections

- **Home** — short introduction and profile photo.
- **About** — an interactive platformer game. Move with **A** and **D**, jump with **Space**, and hit the blocks to reveal information about me (background, university, reading and video games).
- **Qualifications & Activities** — languages, test scores, programming level, swimming and gym.
- **Projects** — Project 1 (Logic Gates): a playable OR gate, the team contribution table, a team photo and a link to our video.

## Files

- `index.html` — page structure and content
- `style.css` — design and responsive layout
- `script.js` — the About game and the OR gate demo
- `project-1-team.png` — Project 1 team photo

## How to view locally

Download or clone the repository and open `index.html` in a browser. No installation is needed.
